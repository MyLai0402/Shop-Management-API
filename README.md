# Shop Management API

A RESTful API for managing shops, customers, products, and shop-related data.

## Technologies

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Pydantic
- Uvicorn
- uv

## Features

- Shop CRUD
- Customer and product management
- Search and filtering
- Pagination
- SQLAlchemy Query
- JOIN and multi-table JOIN
- Relationship between tables
- Data validation with Pydantic
- HTTPException error handling
- Delete and restore data
- Delete history management
- Commit and Rollback
- Database operations with SQLAlchemy
